## Personal experience
I've tried using vim through VSCode with Vim extension for a month. I saw the power of the shortcut for editing/writing files. But the learning curve is steep. I only learnt some basic commands. Then, I am not sure I use an editor often enough for that. Moreover, I struggled copying and pasting from the editor into another window (like a browser) and vice-versa.

Edit: (2 months later)
I started a new coding period in which I need to spend some time in a text editor each day. After some hesitations I decided to reuse vim. It's been two weeks and I'm feeling more and more comfortable with it. I created my own cheat sheet to better memorize the shortcuts.
